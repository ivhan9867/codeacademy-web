Materi "Fondasi Web" ini dibagi menjadi tiga bagian. Anggap ini peta singkat supaya kamu tahu sedang di mana dan apa yang menanti di depan.

## Bagian Persiapan (yang sedang kamu baca)

Delapan modul pendek tentang cara belajar di kelas ini: etika, alat yang dipakai, forum diskusi, sampai glosarium istilah. Tujuannya bukan mengajarkan konsep web, tapi menyiapkanmu supaya bagian berikutnya terasa lebih ringan.

## Bagian Pendahuluan

Tujuh modul yang membahas fondasi konsep web dari dasar:

1. Pengantar Web Programming
2. Cara Internet Bekerja
3. Website dan Halaman Web
4. Web Server
5. Web Browser
6. Anatomi Website
7. Rangkuman Pendahuluan

Kuis Pendahuluan menutup bagian ini.

## Bagian Pengenalan HTML

Delapan modul tempat kamu menulis baris kode pertamamu, semuanya dipraktikkan di Playground:

1. Pengantar HTML
2. Latihan: Halaman Web Pertamamu
3. Bedah Kode: Folder Proyek dan index.html
4. Latihan: Menandai Konten dengan Elemen
5. Anatomi Elemen HTML
6. Atribut pada Elemen HTML
7. Anatomi Dokumen HTML
8. Rangkuman Pengenalan HTML

Kuis Pengenalan HTML menutup bagian ini, lalu Evaluasi Akhir Kelas untuk klaim sertifikat.

## Bagian Pendalaman HTML

Lanjutan dari Pengenalan HTML, membahas variasi elemen yang lebih luas dalam 26 modul: paragraf, heading, list, gambar, format teks blok dan inline, semantic HTML (header/nav/main/footer, article/aside/section), elemen generic (div/span), tabel, formulir dan input, hingga special character. Ditutup dengan Kuis Pendalaman HTML.

## Bagian Dasar & Pendalaman CSS

Membahas selektor, tipografi, warna, box model, hingga positioning dan float untuk menata elemen halaman secara presisi.

## Setelah kelas ini

Kelas ini berfokus pada struktur HTML lengkap serta teknik CSS tradisional (box model, positioning, dan float). Perjalananmu selanjutnya berlanjut ke kelas **CSS Layout Modern: Flexbox & Grid** untuk menguasai sistem tata letak modern yang responsif dan standar industri saat ini.
