Ada puluhan bahasa pemrograman populer di dunia: C, C++, Java, JavaScript, Rust, Go, dan masih banyak lagi. Mengapa Python selalu menjadi pilihan nomor satu bagi jutaan pemula dan pakar data di seluruh dunia?

Jawabannya terangkum dalam satu prinsip: **keterbacaan kode (code readability)**.

Pencipta Python, **Guido van Rossum**, merancang bahasa ini pada akhir tahun 1980-an dengan keyakinan kuat bahwa kode program jauh lebih sering dibaca oleh manusia daripada ditulis. Oleh sebab itu, sintaks Python dibuat sangat dekat dengan bahasa Inggris sehari-hari.

## Perbandingan: Mengucap Salam ke Dunia

Perhatikan perbandingan cara menampilkan tulisan *"Halo Dunia"* di bahasa lain vs Python:

Di bahasa pemrograman C:
```c
#include <stdio.h>
int main() {
    printf("Halo Dunia\n");
    return 0;
}
```

Di Python:
```python
print("Halo Dunia")
```

Hanya satu baris! Tanpa kurung kurawal rumit, tanpa konfigurasi fungsi utama yang membingungkan. Apa yang kamu pikirkan bisa langsung kamu tuangkan menjadi kode yang berjalan.

## Di Mana Saja Python Digunakan?

Python sering disebut sebagai *"Swiss Army Knife"* (pisau serbaguna) teknologi:
1. **Otomatisasi Tugas Rutin**: Mengubah nama ratusan berkas dalam sekejap atau memproses spreadsheet otomatis.
2. **Pengembangan Web Backend**: Menggerakkan layanan web ternama seperti Instagram, Spotify, dan Pinterest.
3. **Data Science & Kecerdasan Buatan (AI)**: Menjadi bahasa standar dunia untuk machine learning, deep learning, dan pengolahan data raksasa.

> *"Simple is better than complex."* (Sederhana lebih baik daripada rumit) — salah satu prinsip inti dari The Zen of Python.

Kini setelah kamu tahu alasan di balik kehebatan Python, mari kita tulis fungsi `print()` kita sendiri di modul berikutnya!
