## Tiga Kunci Sukses Belajar JavaScript

JavaScript adalah bahasa pemrograman pertama kamu di jalur Front-End. Berbeda dengan HTML dan CSS yang bersifat deklaratif (kamu menulis apa yang ingin ditampilkan), JavaScript bersifat instruksional dan logis: kamu memberi perintah langkah demi langkah yang harus dijalankan komputer.

Agar proses belajarmu menyenangkan dan tidak membuat pusing, terapkan tiga prinsip ini:

### 1. Latih "Mental Execution" (Membaca Sebelum Menjalankan)
Sebelum menekan tombol **Jalankan**, biasakan berhenti sejenak selama 5–10 detik. Baca kodenya dari baris teratas ke bawah:
- "Apa yang disimpan variabel ini?"
- "Apakah kondisi `if` ini bernilai benar?"
- "Kira-kira apa yang akan muncul di layar?"

Menebak output di kepala sebelum melihat hasilnya akan membangun intuisi pemrograman yang kuat.

### 2. Jangan Menghafal Sintaks, Pahami Polanya
Programmer profesional tidak menghafal setiap baris perintah di luar kepala. Mereka memahami konsep:
- Kapan butuh menyimpan data (variabel).
- Kapan butuh membuat keputusan (percabangan `if`/`else`).
- Kapan butuh mengulang pekerjaan (perulangan `for`/`while`).
- Kapan butuh merespons klik pengguna (event listener).

Jika kamu lupa tanda kurung atau nama fungsi tertentu, itu sangat wajar. Kamu selalu bisa melihat kembali modul ringkas atau catatan materi.

### 3. Bersahabatlah dengan Pesan Error
Ketika kodenya tidak berjalan dan muncul teks merah di panel Console, jangan panik atau merasa gagal. Pesan error di JavaScript bukanlah hukuman, melainkan pesan jujur dari browser:
> *"Di baris ke-4, ada tanda koma yang terlewat"* atau *"Variabel ini belum kamu buat, tapi sudah kamu panggil"*.

Membaca dan memperbaiki error (*debugging*) adalah 70% pekerjaan harian seorang software engineer.
