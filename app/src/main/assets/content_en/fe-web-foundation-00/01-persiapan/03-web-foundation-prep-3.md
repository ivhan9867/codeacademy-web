Good news: you don't need to install anything to get started.

## Everything Through the Playground

Unlike most programming classes that require you to install a code editor, configure terminals, or get confused by folder paths on your laptop, all practice exercises in this course can be done directly through the **Playground** feature built right into this app. Here is how:

1. Open the Playground using the "Try in Playground" button on any code example
2. Type or modify the code
3. See the results instantly, with no installation or extra setup required

No intimidating black screens, no frustrating installation error messages before you even get a chance to learn anything.

## What You Need Today

- Your smartphone
- An internet connection
- This app open

When you eventually become a professional web developer, you will still use code editors like VS Code on a laptop. But that is not a requirement for today — allow yourself to focus on the logic first, not the tools.
