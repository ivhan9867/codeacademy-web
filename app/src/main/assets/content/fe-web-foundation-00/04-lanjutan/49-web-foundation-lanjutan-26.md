Perjalanan panjang! Dari paragraf sederhana sampai formulir yang bisa menerima data pengguna. Yuk, rangkum semuanya sebelum lanjut ke kuis.

## Poin-poin utama

- **Paragraf dan Heading**: `<p>` untuk teks umum, `<h1>` sampai `<h6>` untuk judul berjenjang yang menyusun outline halaman
- **List**: `<ul>` untuk daftar tanpa urutan, `<ol>` untuk daftar berurutan (dengan atribut `type`, `start`, `reversed`), `<dl>`/`<dt>`/`<dd>` untuk pasangan istilah dan penjelasan
- **Gambar**: `<img>` dengan atribut `src` dan `alt`, ukurannya diatur lewat `width` atau `height` (salah satu saja)
- **Format teks blok**: `<blockquote>` untuk kutipan panjang, `<pre>` untuk teks yang mempertahankan spasi dan baris apa adanya, `<figure>`/`<figcaption>` untuk konten mandiri beserta keterangannya
- **Format teks inline**: `<a>` untuk tautan, `<em>`/`<strong>` untuk penekanan, `<q>` untuk kutipan pendek, `<cite>` untuk rujukan karya, `<dfn>` untuk definisi istilah, `<sub>`/`<sup>` untuk subscript dan superscript, `<mark>` untuk sorotan, `<br>` untuk baris baru
- **Semantic HTML**: `<header>`, `<footer>`, `<main>`, `<nav>` untuk struktur besar halaman; `<article>`, `<aside>`, `<section>` untuk konten yang lebih spesifik dan bermakna
- **Generic element**: `<div>` (block) dan `<span>` (inline) untuk pengelompokan tanpa makna semantik khusus
- **Tabel**: `<table>`, `<tr>`, `<td>`/`<th>` sebagai struktur dasar, `colspan`/`rowspan` untuk spanning cell, serta `caption`, `thead`/`tbody`/`tfoot`, `scope`, dan `headers` untuk tabel yang lebih rapi dan mudah diakses
- **Formulir**: `<input>` dengan berbagai `type`, `<textarea>` untuk teks panjang, `<label>` sebagai keterangan, atribut seperti `name`, `required`, `placeholder`, `pattern`, dan lainnya untuk validasi, lalu `<form>` dengan `action` dan `method` untuk mengirim data
- **Special character**: character reference (`&nama;` atau `&#angka;`) untuk menampilkan karakter yang punya arti khusus di HTML atau simbol di luar karakter dasar

## Halaman profilmu sekarang

Bayangkan halaman profil yang kamu bangun sepanjang bagian ini: header dengan navigasi yang benar-benar berfungsi, konten utama yang terbagi rapi jadi beberapa artikel dan section, kartu info singkat lengkap dengan tabel data, dan (kalau kamu ikuti latihannya) formulir kontak sederhana di bagian akhir. Itu semua dibangun murni dengan HTML, tanpa satu baris CSS atau JavaScript pun.
