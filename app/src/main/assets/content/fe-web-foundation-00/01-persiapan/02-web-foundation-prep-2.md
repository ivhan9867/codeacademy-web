Kelas ini adalah pintu gerbang awal perjalanan Front-End: mencakup konsep web, HTML lengkap, hingga CSS dasar dan positioning.

## Kenapa mulai dari sini, bukan langsung HTML?

Bayangkan belajar HTML dan CSS tanpa tahu dulu apa itu server, browser, atau kenapa halaman bisa muncul di layar. Bisa saja jalan, tapi rasanya seperti menghafal resep masakan tanpa tahu kenapa air harus dipanaskan dulu sebelum bumbu dimasukkan — tag-tagnya kehafal, tapi logikanya kosong.

Sebelum menulis baris kode pertama, penting untuk tahu dulu: apa itu website, kenapa dia bisa muncul di layar HP-mu, dan bagaimana permintaan dari HP-mu sampai ke server lalu kembali lagi jadi tampilan yang kamu lihat.

Website bukan cuma tempat baca berita. Transfer uang, edit foto online, sampai nonton video, semuanya jalan lewat mekanisme dasar yang sama, dan itu yang akan kamu pelajari di kelas ini. Begitu paham fondasinya, modul HTML dan CSS setelah ini akan jauh lebih masuk akal, bukan sekadar hafal tag satu per satu.

## Apa yang akan kamu dapat

Setelah menyelesaikan kelas ini, kamu akan bisa menjelaskan bagaimana internet menghubungkan komputer di seluruh dunia, apa bedanya website dan halaman web, apa peran server dan browser, dan bagaimana HTML, CSS, JavaScript bekerja sama membentuk satu halaman yang kamu lihat sehari-hari.
