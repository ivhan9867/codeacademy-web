## Semua lewat Playground

Berbeda dari kelas pemrograman kebanyakan yang mengharuskanmu install code editor, mengatur terminal, sampai bingung path folder di laptop, semua praktik di kelas ini bisa langsung dikerjakan lewat fitur **Playground** yang sudah ada di aplikasi ini. Caranya:

1. Buka Playground dari tombol "Coba di Playground" di setiap contoh kode
2. Ketik atau ubah kodenya
3. Lihat hasilnya langsung, tanpa perlu proses install atau setup tambahan

Tidak ada layar hitam menakutkan, tidak ada pesan error instalasi yang bikin frustrasi sebelum sempat belajar apa-apa.

## Yang kamu butuhkan hari ini

- HP kamu
- Koneksi internet
- Aplikasi ini terbuka

Kalau nanti kamu lanjut jadi web developer sungguhan, kamu tetap akan pakai code editor seperti VS Code di laptop. Tapi itu bukan kebutuhan hari ini — biarkan dirimu fokus dulu ke logikanya, bukan ke tools-nya.
