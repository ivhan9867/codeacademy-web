It's time to apply everything we've learned about positioning and floating to the Profile Page. In the upcoming practice, we will reposition the `<aside>` element so that it sits alongside the content rather than stacking underneath it.

This practice will be a bit longer because once the layout is neat on large screens, we will also make the page **responsive**—displaying well on small screens like mobile phones—using *media query* techniques. That way, the Profile Page we've been building since the beginning of this module will truly be ready for use on any device.

Get your latest Profile Page project ready, and let's start with the two-column layout.
