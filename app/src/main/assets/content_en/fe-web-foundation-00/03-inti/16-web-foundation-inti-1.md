You already know what a website is, how a browser requests a page from a server, and that a page is built using HTML, CSS, and JavaScript. Starting from this module, we stop just reading about them and start **writing actual code**.

## What on Earth is HTML?

**HTML** (*HyperText Markup Language*) is the language used to build the **structure** of a web page: where headings go, where paragraphs are, where images and links live. The keyword here is *markup*. You are not telling a computer to calculate something; you are **marking up** the page content so the browser understands the role of each part.

Because of this, HTML is not a programming language like Python or JavaScript. HTML has no math logic or branching conditions. It is a markup language, and that is precisely its strength: it is simple, easy to learn, and used by every single web page in the world.

Think of it like an animal's skeleton. The skeleton defines the basic shape: a cat has four legs and a tail, a bird has wings and a beak. The color of the fur and how it moves come later. On a web page:

- **HTML** is the skeleton (what the page contains)
- **CSS** is the skin and fur (how it looks)
- **JavaScript** is the movement (how the page reacts)

## A Glimpse of the Final Result

Here is a very small piece of HTML code. You don't need to understand it yet, just take a look:

```html
<h1>Rani's Profile</h1>
<p>A student who is learning how to build websites.</p>
```

The result in the browser: a large, bold heading followed by a paragraph below it. It still looks plain, and that's intentional. Making pages look pretty is the job of CSS, which you will learn in the CSS Basics section of this course. Our focus right now is building the correct structure.
