Kelas ini cukup untuk memberimu fondasi, tapi kalau kamu ingin menggali lebih jauh, beberapa sumber berikut bisa membantu:

- **MDN Web Docs** — dokumentasi resmi dan paling lengkap untuk HTML, CSS, dan JavaScript. Ini yang dipakai developer profesional saat butuh detail teknis yang tidak dibahas di kelas manapun.
- **Arsip CERN** — rekonstruksi website pertama di dunia, bisa dijelajahi langsung untuk melihat betapa sederhananya web di awal kemunculannya, jauh sebelum ada gambar atau warna.
- **freeCodeCamp** — pengantar ringan untuk HTML bagi pemula, cocok kalau kamu ingin latihan tambahan di luar Playground aplikasi ini.
- **CSS-Tricks dan MDN** — panduan mendalam soal Flexbox dan tata letak CSS lainnya, berguna nanti begitu kamu mulai merasa CSS "susah diatur rapi".

Tidak perlu dibaca semua sekarang. Simpan saja sebagai bahan lanjutan kalau nanti butuh penjelasan yang lebih teknis dari yang dibahas di kelas ini.
