Inget analogi kerangka tubuh di modul HTML? HTML itu kerangkanya — menentukan apa saja isi halaman. Sekarang saatnya kita kasih "kulit dan bulu"-nya: **CSS**.

Coba bayangin halaman HTML tanpa CSS sama sekali. Semua teks numpuk rapat, warnanya hitam-putih polos, gak ada jarak yang enak dilihat. Itulah kenapa CSS ada — singkatan dari *Cascading Style Sheet*, standar resmi buat ngatur tampilan dokumen HTML: warna, ukuran, jarak, posisi, dan banyak lagi.

Satu hal penting: **CSS bukan bahasa pemrograman**. Gak ada if-else, gak ada perulangan, gak ada logika di dalamnya. CSS cuma bahasa *deklaratif* — kamu tinggal bilang "elemen ini warnanya biru" dan browser yang ngurus sisanya. Beda total sama JavaScript yang nanti akan kamu pelajari di course lain.

Kenapa CSS penting buat kamu sebagai calon web developer?
- Satu file CSS bisa dipakai buat banyak halaman HTML sekaligus — gak perlu atur styling berulang-ulang.
- Semua browser modern (Chrome, Firefox, Safari, Edge) udah dukung CSS versi terbaru.
- Tanpa CSS, sebagus apapun struktur HTML kamu, halamannya tetap kelihatan mentah.

Di bagian ini kamu akan belajar dasar-dasarnya dulu: cara nulis aturan CSS, tiga cara menyambungkannya ke HTML, dan styling paling dasar kayak ngasih warna teks. Materi CSS yang lebih dalam (ngatur layout, posisi elemen, responsive design) ada di course terpisah setelah ini.
