## Mindset Shift: From Text Pages to App Interfaces

Modern websites are no longer just digital paper scrolls filled with articles flowing from top to bottom. When you open an online shopping app, social media, or work dashboard, your screen is filled with various interactive blocks:

- A top navigation bar that stretches neatly from the left edge to the right edge.
- Product cards that line up in balanced columns on a laptop screen, then automatically wrap neatly when opened on a smartphone screen.
- A chat box or side widget (*sidebar*) that stays in position while the page is scrolled.

All of the layout magic above is not built with negative margin tricks or manual pixel guesswork, but with two official modern browser standards: **CSS Flexible Box (Flexbox)** and **CSS Grid Layout (Grid)**.

## Your Learning Roadmap

This course is systematically designed into 5 main stages:

1. **Preparation**: Get to know the layout mindset, the decision map for when to use Flexbox or Grid, and how to configure the interactive Playground so visualizations are clear.
2. **Introduction**: Trace the reasons modern layouts were born, the limitations of past eras (*float & positioning hacks*), and the core philosophy of layout formatting.
3. **Core Material (Flexbox)**: Master the 1-dimensional system in depth — directing the axis, aligning content, wrapping multiple lines, and assembling a responsive navigation bar.
4. **Advanced Material (CSS Grid)**: Conquer the 2-dimensional system — dividing rows and columns, using fraction (`fr`) units, drawing blueprints with `grid-template-areas`, and automatic card gallery tricks without *media queries*.
5. **Project & Evaluation**: Weave both modules together in an integrated dashboard page project and a certification graduation quiz.

## The Best Way to Learn in This App

Layout is a visual skill. You cannot master it simply by memorizing property names. The best approach is:

1. **Observe the Patterns**: Pay attention to the axis diagrams and container boxes in each module's explanation.
2. **Test in the Playground**: Whenever there is a starter code block, tap the **HTML/CSS Playground** tab, run the code, then change its values (for example, change `flex-start` to `center`).
3. **Use the Live Preview Button**: Observe instant changes in the WebView preview area. Don't be afraid of making mistakes—you can always press the **Reset** button to return to the module's initial code.
