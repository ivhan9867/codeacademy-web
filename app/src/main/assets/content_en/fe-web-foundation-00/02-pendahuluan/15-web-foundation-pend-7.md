## Key Points

- **Introduction to web programming**: The web is used in almost every field, and learning web programming means shifting from being just a user to becoming a creator.
- **How the internet works**: Computers are connected via networks. Network switches connect multiple computers at once, and the internet is a network of networks connected through modems and ISPs.
- **Websites and web pages**: A web page is a single page, while a website is a collection of web pages connected via hyperlinks. The Web is a service that runs on top of the internet, and the idea was proposed by Tim Berners-Lee at CERN in 1989.
- **Web server**: Servers store and send website content. The browser, as the client, sends a request, and the server replies with a response via HTTP. DNS translates domain names into IP addresses.
- **Web browser**: Browsers retrieve and display web pages. A URL consists of a protocol, domain name, and path. Status codes like 200 and 404 indicate the result of a request.
- **Anatomy of a website**: HTML forms the structure, CSS manages the appearance, and JavaScript provides interactivity.

## From typing an address to page display

1. You type a URL into the address bar and press enter.
2. The browser looks for the IP address of that domain (checks the DNS cache, then asks a DNS server if necessary).
3. The browser sends an HTTP request to the web server at that IP address.
4. The web server processes the request and sends an HTTP response containing HTML, CSS, JavaScript, and other assets.
5. The browser assembles everything: HTML becomes the skeleton, CSS provides the style, and JavaScript adds interactivity.
6. The web page appears on your screen.

## Key Terms

- **Client**: The party requesting data (in this case, the browser).
- **Server**: The computer that stores and serves data.
- **Request and response**: The request from the client and the response from the server.
- **HTTP and HTTPS**: Protocols for data exchange between browsers and servers (HTTPS is encrypted).
- **DNS**: The system that converts domain names into IP addresses.
- **URL**: The complete address of a web page.
- **HTML, CSS, JavaScript**: The structure, appearance, and interactivity of a web page.
