## Preparing the Font Styling Exercise

We have explored various text styling properties in CSS—ranging from separating font and text properties, setting size (`font-size`) and weight (`font-weight`), to connecting modern fonts from Google Fonts. These concepts will become much easier to understand when you practice them directly on a real project.

Now it is time to apply all this typography knowledge to beautify the **Profile Page** project you are building.

## Exercise Goals

In this step-by-step exercise, you have two main goals:

1. **Build a Clean Visual Hierarchy**: Set the sizes of headings, subheadings, and body paragraphs so readers can easily distinguish between primary and supplementary information.
2. **Add a Touch of Unique Character**: Replace the system's default font (*generic font family*) with a font of your choice from Google Fonts to make the profile page look more professional and modern.

## Preview of the Code You Will Write

Here is a quick preview of the CSS rules you will apply to the profile elements:

```css
body {
  font-family: 'Poppins', sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
  text-align: center;
}
```

Make sure you have your latest Profile Page project open in your text editor. Once you are ready, let's move on to the first exercise step!
