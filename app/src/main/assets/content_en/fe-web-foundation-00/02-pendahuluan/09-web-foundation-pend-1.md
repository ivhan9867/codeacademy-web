Internet, website, web page, browser: four terms you have almost certainly heard often. But can you explain the difference between them, and how all four work together? In this chapter, we'll sort all of that out first before you start writing code.

## The web is everywhere

Searching for information, studying, shopping, booking transportation, and even managing daily schedules: we now do most of these through the web. According to a DataReportal report (Digital 2026), around 230 million people in Indonesia were already using the internet by the end of 2025, or roughly 8 out of 10 residents. The more people are online, the greater the demand for well-built websites.

## From user to creator

So far, you have probably spent more time on the *user* side. When learning web programming, your role shifts to becoming a *creator*: you are the one deciding what appears on the screen and how people interact with it.

The role of a website is broad too. For a business, a website is like a store open 24 hours a day: introducing products, accepting orders, and reaching customers far from a physical storefront. For schools, communities, or organizations, a website is a place to share information with many people at once.

## Roadmap for this chapter

So you don't feel lost when you start coding, we begin with the foundations:

1. How the internet connects computers around the world
2. The difference between a website and a web page
3. Web servers: the computers that store and send website contents
4. Web browsers and how they work
5. Anatomy of a web page: HTML, CSS, and JavaScript

At the end of the chapter, there is a summary and a short quiz to check your understanding.

> Warm-up: think of one website you open most often. By the end of this chapter, you will be able to explain how that page reaches your screen.
