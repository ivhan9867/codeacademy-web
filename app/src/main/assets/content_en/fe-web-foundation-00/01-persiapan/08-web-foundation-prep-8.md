This class is enough to give you a foundation, but if you want to dig deeper, the following resources can help:

- **MDN Web Docs** — the official and most comprehensive documentation for HTML, CSS, and JavaScript. This is what professional developers use when they need technical details not covered in any class.
- **CERN Archive** — a reconstruction of the world's first website, which you can explore directly to see how simple the web was at its inception, long before images or colors existed.
- **freeCodeCamp** — a gentle introduction to HTML for beginners, great if you want extra practice outside of this app's Playground.
- **CSS-Tricks and MDN** — in-depth guides on Flexbox and other CSS layouts, useful later once you start feeling like CSS is "hard to keep neat."

You don't need to read all of these right now. Just save them as further reading for when you eventually need more technical explanations than what is covered in this class.
