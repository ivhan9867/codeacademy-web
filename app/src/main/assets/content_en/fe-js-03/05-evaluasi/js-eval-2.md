## Summary of the 6 Pillars of Modern JavaScript

### 1. Variables & Data Types
- Prefer **`const`** for all data. Only use **`let`** when a value genuinely needs to change. Avoid `var`.
- 5 Primitive Types: `String`, `Number`, `Boolean`, `undefined`, and `null`.

### 2. Operators & Logic
- Always use strict comparison **`===`** and **`!==`** (avoid `==`).
- Combine conditions with logical operators: `&&` (AND), `||` (OR), `!` (NOT).

### 3. Control Flow
- Make decisions with **`if / else if / else`** or **`switch`**.
- Automate repetitive work with **`for`** or **`while`** loops.

### 4. Data Structures (Array & Object)
- **Array (`[...]`)**: An ordered collection shelf with indices starting at 0. Manage it with `.push()`, `.map()`, and `.filter()`.
- **Object (`{...}`)**: A representation of a real-world entity with key-value pairs (`key: value`). Access properties with dot notation (`obj.nama`).

### 5. Functions
- Reusable blocks of recipe code (*DRY*).
- Use **Arrow Functions (`=>`)** for concise and expressive syntax.

### 6. DOM & Web Interactivity
- Capture HTML elements using **`document.querySelector()`**.
- Change text and styles using **`.textContent`** and **`.style`**.
- Respond to user actions using **`.addEventListener("click", handler)`**.
