This "Web Foundation" course is divided into several sections. Think of this as a quick roadmap so you know where you currently are and what lies ahead.

## Preparation Section (the one you are reading now)

Eight short modules on how to learn in this class: study habits, tools used, discussion forums, up to the terminology glossary. The goal is not to teach web concepts, but to get you ready so the upcoming sections feel much lighter.

## Introduction Section

Seven modules covering the foundational concepts of the web from scratch:

1. Introduction to Web Programming
2. How the Internet Works
3. Websites and Web Pages
4. Web Server
5. Web Browser
6. Anatomy of a Website
7. Introduction Summary

An Introduction Quiz wraps up this section.

## Introduction to HTML Section

Eight modules where you will write your very first lines of code, all practiced inside the Playground:

1. Introduction to HTML
2. Exercise: Your First Web Page
3. Code Breakdown: Project Folders and index.html
4. Exercise: Marking Up Content with Elements
5. Anatomy of HTML Elements
6. Attributes in HTML Elements
7. Anatomy of an HTML Document
8. Introduction to HTML Summary

An Introduction to HTML Quiz wraps up this section, followed by the Final Class Evaluation to claim your certificate.

## Advanced HTML Section

A continuation of HTML Introduction, covering a broader variety of elements across 26 modules: paragraphs, headings, lists, images, block and inline text formatting, semantic HTML (header/nav/main/footer, article/aside/section), generic elements (div/span), tables, forms and inputs, up to special characters. Concluded with the Advanced HTML Quiz.

## CSS Basics & Advanced Section

Covers selectors, typography, colors, the box model, up to positioning and float to precisely style and arrange page elements.

## After this class

This course focuses on complete HTML structure as well as traditional CSS techniques (box model, positioning, and float). Your journey will then continue to the **Modern CSS Layout: Flexbox & Grid** class to master modern, responsive layout systems that are current industry standards.
