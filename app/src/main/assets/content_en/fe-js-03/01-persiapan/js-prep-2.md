# Learning Roadmap: From Basic Syntax to Interactive Web

Learning programming often feels confusing if you don't know where the journey is heading. In this course, the curriculum is structured step by step like building a multi-story house: a solid foundation is laid first before installing wiring and moving parts.

---

## Your Five Learning Stages

Your journey in this course is divided into five main sections:

```text
[01. Preparation] ──> [02. JS Basics] ──> [03. Logic & Flow]
                                                     │
[05. Final Project] <── [04. Functions, Objects & DOM] <──┘
```

### Section 1: Preparation (Modules 1 – 3)
Set up your learning mindset and get comfortable using CodeAcademy's interactive editor and **Console** panel to see code results immediately.

### Section 2: JavaScript Basics (Modules 4 – 8)
Learn the brief history and role of JavaScript in the browser, how to connect it to an HTML file, print information with `console.log()`, follow basic code formatting rules, and recognize common types of error messages.

### Section 3: Logic & Program Flow (Modules 9 – 16)
Study the core logic of programming:
- **Variables (`let` & `const`)**: Containers for storing data in memory.
- **Data Types**: Text (*string*), numbers (*number*), and truth values (*boolean*).
- **Operators**: Math calculations and value comparisons (`===`).
- **Conditionals (`if` / `else` / `switch`)**: Letting a program choose between execution paths.
- **Loops (`for` / `while`)**: Completing repetitive tasks without retyping code.
- **Basic Arrays**: Storing lists of multiple items in one place.

### Section 4: Functions, Objects & the DOM (Modules 17 – 24)
Start connecting JavaScript code to visual elements on the page:
- **Functions & Arrow Functions**: Reusable code recipes you can call over and over.
- **Scope**: Understanding variable lifetime boundaries so names don't collide.
- **Objects**: Storing paired data (*keys* and *values*).
- **Array Methods (`forEach`, `map`, `filter`)**: Processing collections of data the modern way.
- **DOM & Event Listeners**: Selecting HTML elements (`querySelector`) and responding to real user actions (like button clicks).
- **Intro to Asynchronous JS**: Understanding task queues with `Promise` and `async`/`await`.

### Section 5: Project & Evaluation (Modules 25 – 26)
Combine every piece of knowledge into one complete interactive web app: **a Simple To-Do List App**. You'll see firsthand how clicking a button adds a new task directly to the screen!

After completing these 26 modules, your web pages will no longer be static and rigid. You will be able to build mini calculators, interactive quizzes, toggleable navigation menus, and smart forms that validate user input in real time.
