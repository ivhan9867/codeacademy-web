Here are several terms that will frequently appear throughout this course. You don't need to memorize them right now—just use them as a reference whenever you forget what something means.

- **Browser** — an application on your device that translates website code into a visual display you can see and interact with. Like a projector that displays the contents of a document.
- **Client** — the party sending a request (for example, your phone when opening a website) and waiting for a reply from the server. Your position is the one "requesting."
- **Server** — another computer, usually located far away in a data center, that stores and sends back the data requested by the client. Its position is the one "providing."
- **DNS (Domain Name System)** — the phonebook of the internet; translates human-friendly domain names into IP addresses that machines understand.
- **HTML** — the skeleton or structure of a web page; determines what is on the page.
- **CSS** — the visual styling layer on top of HTML; determines how it looks.
- **Selector** — a target marker in CSS that determines which HTML elements will receive styling rules.
- **HTTP/HTTPS** — the language used by clients and servers to send requests and responses back and forth over the internet.
- **Plain text vs rich text** — plain text is unformatted text (used for program code); rich text already has visual formatting like a Word document.
- **Playground** — the hands-on coding practice feature in this app, where you write and run code without needing additional software.
- **WWW (World Wide Web)** — a collection of pages and documents interconnected over the internet, accessed through a browser.
- **Element** — the building block of HTML that marks a piece of content along with its role, such as a paragraph or heading.
- **Opening tag and closing tag** — markers for the start and end of an element. A closing tag uses a forward slash before the element name.
- **Attribute** — additional information on an element, written inside the opening tag as a name and value pair.
- **Child-element** — an element located inside another element (its parent).
- **DOM Tree** — the hierarchical structure of elements within a document, depicted like a tree or family lineage.
- **Doctype** — the first line of an HTML document that tells the browser which HTML standard is being used.

If you run into these terms again in later modules and forget what they mean, there's no need to feel embarrassed about coming back here.
