You have already written your first HTML document: headings, paragraphs, and a proper basic structure. That is an essential foundation, yet it is only the surface. Now it is time to dive deeper.

## What is different from the previous section?

In Introduction to HTML, you learned **structure**: how a document is built from the `html`, `head`, and `body` skeleton. In Deeper HTML, you learn **variety**: the other elements that make a page truly useful and complete.

Some of the things you will learn in this section:

- Core content elements such as paragraphs, headings, and different kinds of lists
- Displaying images and controlling their dimensions
- Text formatting: quotations, preformatted text, text emphasis, abbreviations, and similar elements
- Semantic HTML: organizing a page with meaningful elements like header, nav, main, and footer
- Generic elements (div) for grouping content
- Tables for displaying structured data
- Forms and various input types for collecting data from users

## Continuing project

Throughout this section, you will keep expanding the profile page you started earlier. Each module adds a new capability to that page, until you end up with a profile page far richer than just headings and paragraphs.
