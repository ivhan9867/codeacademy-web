In the previous exercise, we applied fonts from Google Fonts with `font-family` and changed text colors with `color`. Now, after learning box model components like padding, border, and margin, it is time to apply all of them to the Profile Page we built.

In the upcoming series of exercises, we will:

- set image dimensions so they display proportionally;
- create a *card style* effect on each article section;
- turn the header into a *jumbotron* with cleaner navigation;
- tidy up the spacing between content and the browser edges.

Once all of these steps are complete, the Profile Page—which started out looking quite simple—will transform into a much more polished and visually appealing layout. Prepare your latest Profile Page project, and let's start with the images.
