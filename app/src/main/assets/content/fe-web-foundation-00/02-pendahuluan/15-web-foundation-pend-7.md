## Poin-poin utama

- **Pengantar web programming**: web dipakai di hampir semua bidang, dan belajar web programming berarti berpindah dari sekadar pengguna menjadi pembuat.
- **Cara internet bekerja**: komputer terhubung lewat jaringan. Network switch menyambungkan banyak komputer sekaligus, dan internet adalah jaringan dari jaringan-jaringan yang saling terhubung lewat modem dan ISP.
- **Website dan halaman web**: halaman web adalah satu halaman tunggal, sedangkan website adalah kumpulan halaman web yang terhubung lewat hyperlink. Web adalah layanan yang berjalan di atas internet, dan gagasannya diusulkan Tim Berners-Lee di CERN pada 1989.
- **Web server**: server menyimpan dan mengirim isi website. Browser sebagai client mengirim request, dan server membalas dengan response lewat HTTP. DNS menerjemahkan nama domain menjadi alamat IP.
- **Web browser**: browser mengambil dan menampilkan halaman web. URL terdiri dari protocol, domain name, dan path. Kode status seperti 200 dan 404 menandakan hasil permintaan.
- **Anatomi website**: HTML membentuk struktur, CSS mengatur tampilan, dan JavaScript menghadirkan interaksi.

## Dari ketik alamat sampai halaman tampil

1. Kamu mengetik URL di address bar lalu menekan enter.
2. Browser mencari alamat IP dari domain tersebut (cek DNS cache, lalu tanya DNS server bila perlu).
3. Browser mengirim HTTP request ke web server di alamat IP itu.
4. Web server memproses permintaan, lalu mengirim HTTP response berisi HTML, CSS, JavaScript, dan aset lain.
5. Browser merakit semuanya: HTML menjadi kerangka, CSS memberi gaya, JavaScript menambah interaksi.
6. Halaman web tampil di layarmu.

## Istilah kunci

- **Client**: pihak yang meminta data (dalam hal ini browser)
- **Server**: komputer yang menyimpan dan menyajikan data
- **Request dan response**: permintaan dari client dan tanggapan dari server
- **HTTP dan HTTPS**: protokol pertukaran data antara browser dan server (HTTPS terenkripsi)
- **DNS**: sistem yang mengubah nama domain menjadi alamat IP
- **URL**: alamat lengkap sebuah halaman web
- **HTML, CSS, JavaScript**: struktur, tampilan, dan interaksi halaman web
