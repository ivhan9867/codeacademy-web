## Menyiapkan Latihan Font Styling

Kita sudah menjelajahi berbagai properti styling teks di CSS—mulai dari memisahkan properti font dan text, mengatur ukuran (`font-size`), ketebalan (`font-weight`), hingga cara menghubungkan font modern dari Google Fonts. Teori-teori ini akan jauh lebih mudah dipahami saat kamu langsung mempraktikkannya pada proyek nyata.

Sekarang saatnya kamu menerapkan semua pengetahuan tipografi ini untuk mempercantik berkas **Halaman Profil** yang sedang kamu bangun.

## Tujuan Latihan

Di latihan bertahap ini, kamu memiliki dua tujuan utama:

1. **Membangun Hierarki Visual yang Rapi**: Mengatur ukuran teks judul, subjudul, dan isi paragraf agar pembaca dapat membedakan informasi utama dan pelengkap dengan mudah.
2. **Memberikan Sentuhan Karakter Unik**: Mengganti jenis font bawaan sistem (*generic font family*) dengan font pilihan dari Google Fonts agar halaman profil terlihat lebih profesional dan modern.

## Gambaran Kode yang Akan Dibuat

Berikut gambaran singkat aturan CSS yang akan kamu terapkan pada elemen-elemen profil:

```css
body {
  font-family: 'Poppins', sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  font-size: 2rem;
  font-weight: 700;
  text-align: center;
}
```

Pastikan kamu sudah membuka proyek Halaman Profil terakhirmu di teks editor. Jika sudah siap, mari kita lanjut ke langkah latihan pertama!
