In the previous modules, you were introduced to CSS: what it is, how it works, how to write rules, and basic concepts like *inheritance*, *grouping selectors*, and *rule order*. That is a strong foundation. However, if you look at the profile page you created earlier, it probably still feels simple and not yet "alive."

In this advanced section, we will explore CSS further. You will learn:

- More diverse **selectors**, to target elements with precision.
- **Text formatting**, starting from fonts, sizes, weights, to line spacing.
- **Coloring**, including how to write color values and adjust transparency.
- **The Box Model**, which is how the browser calculates the space occupied by each element.
- **Positioning and floating**, to arrange the positions of elements on the screen.
- **Responsiveness**, so that the page remains comfortable to view on small screens.

Each section comes with exercises that directly apply the knowledge to the profile page. Therefore, you won't just be reading theory, but you will also see real changes at every step.

## Final Target Overview

At the end of the module, that simple profile page will transform into a page with a colored header, neat content cards, clear navigation, and an appearance that remains pleasant to view on mobile phones. The difference will be clearly visible when you compare the initial result with the final result.
