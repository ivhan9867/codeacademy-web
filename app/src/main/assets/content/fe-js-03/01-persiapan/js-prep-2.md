# Peta Belajar: Dari Sintaks Dasar ke Web Interaktif

Belajar pemrograman sering kali terasa membingungkan jika kamu tidak tahu ke mana arah perjalanannya. Di kelas ini, kurikulum disusun secara bertahap seperti membangun rumah bertingkat: fondasi yang kokoh diletakkan terlebih dahulu sebelum memasang instalasi listrik dan perabotan yang bergerak.

---

## Lima Tahapan Belajar Kamu

Perjalanan kamu di kelas ini terbagi ke dalam lima bagian utama:

```
[01. Persiapan] ──> [02. Dasar-Dasar JS] ──> [03. Logika & Alur]
                                                        │
[05. Proyek Akhir] <── [04. Fungsi, Objek & DOM] <──────┘
```

### Bagian 1: Persiapan (Modul 1 – 3)
Mempersiapkan lingkungan belajar dan membiasakan diri menggunakan editor interaktif CodeAcademy serta panel **Console** untuk melihat hasil kode secara instan.

### Bagian 2: Dasar-Dasar JavaScript (Modul 4 – 8)
Memahami sejarah singkat dan peran JavaScript di browser, cara menghubungkannya ke file HTML, mencetak informasi menggunakan `console.log()`, aturan penulisan kode, serta cara mengenali jenis-jenis pesan error umum.

### Bagian 3: Logika & Alur Program (Modul 9 – 16)
Mempelajari inti logika pemrograman:
- **Variabel (`let` & `const`)**: Wadah untuk menyimpan data di memori.
- **Tipe Data**: Teks (*string*), angka (*number*), dan kebenaran (*boolean*).
- **Operator**: Perhitungan matematika dan pembanding nilai (`===`).
- **Percabangan (`if` / `else` / `switch`)**: Membuat program mampu memilih jalur aksi.
- **Perulangan (`for` / `while`)**: Menyelesaikan tugas berulang tanpa mengetik ulang.
- **Array Dasar**: Menyimpan daftar banyak item dalam satu tempat.

### Bagian 4: Fungsi, Objek & DOM (Modul 17 – 24)
Mulai menghubungkan kode JavaScript dengan elemen visual di halaman:
- **Fungsi & Arrow Function**: Resep kode yang dapat dipanggil berkali-kali.
- **Scope**: Memahami batas hidup variabel agar tidak saling bertabrakan.
- **Objek**: Menyimpan data berpasangan (*kunci* dan *nilai*).
- **Array Methods (`forEach`, `map`, `filter`)**: Memproses kumpulan data secara modern.
- **DOM & Event Listener**: Menangkap elemen HTML (`querySelector`) dan merespons aksi nyata pengguna (misalnya klik tombol).
- **Pengantar Asinkron**: Mengenal konsep antrean tugas dengan `Promise` dan `async`/`await`.

### Bagian 5: Proyek & Evaluasi (Modul 25 – 26)
Menggabungkan semua potongan ilmu menjadi satu aplikasi web interaktif yang utuh: **Aplikasi To-Do List Sederhana**. Kamu akan melihat bagaimana klik tombol menambah tugas baru ke layar secara langsung!

---

## Apa yang Akan Kamu Kuasai?
Setelah menyelesaikan 26 modul ini, halaman web yang kamu buat tidak lagi statis dan kaku. Kamu dapat membuat kalkulator mini, kuis interaktif, menu navigasi buka-tutup, dan formulir pintar yang memeriksa data pengguna secara real-time.

Mari kita lanjutkan ke modul berikutnya untuk mencoba langsung editor interaktif dan panel Console!
