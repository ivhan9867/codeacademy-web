Remember the human skeleton analogy from the HTML module? HTML is the skeleton — it defines what content is on the page. Now it is time to add its "skin and coat": **CSS**.

Imagine an HTML page with no CSS at all. All the text stacks tightly together, everything is plain black and white, and there is no comfortable spacing. That is why CSS exists — short for *Cascading Style Sheet*, the official standard for controlling how HTML documents look: colors, sizes, spacing, positioning, and much more.

One important thing: **CSS is not a programming language**. There is no if-else, no loops, and no logic inside it. CSS is simply a *declarative* language — you just state "this element is blue" and the browser handles the rest. That is completely different from JavaScript, which you will learn later in another course.

Why is CSS important for you as an aspiring web developer?
- One CSS file can be reused across many HTML pages at once — no need to repeat styling over and over.
- All modern browsers (Chrome, Firefox, Safari, Edge) already support the latest CSS features.
- Without CSS, no matter how great your HTML structure is, the page still looks raw.

In this section, you will learn the fundamentals first: how to write CSS rules, the three ways to connect CSS to HTML, and the most basic styling such as coloring text. Deeper CSS topics (layout control, element positioning, responsive design) are covered in a separate course after this.
